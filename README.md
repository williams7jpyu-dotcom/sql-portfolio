# SQL Portfolio — データ分析クエリ集

実務を想定したビジネスデータに対し、SQLで分析を行うポートフォリオです。
スキーマ設計からサンプルデータ作成、分析クエリの実装までを一貫して行っています。

|---|------------|------|------|

## 使用技術・SQLスキル

### テーブル設計

- 正規化（第3正規形）に基づくリレーショナル設計
- 外部キー制約によるデータ整合性の保証
- パフォーマンスを意識したインデックス設計（検索頻度の高いカラムに付与）
- ENUM型による値の制約

### 分析クエリ

| 技術 | 使用箇所 |
|------|---------|
| ウィンドウ関数（LAG, NTILE, ROW_NUMBER） | 前月比算出、顧客デシル分析、最新ステージ特定 |
| CTE（共通テーブル式） | 複数ステップの分析ロジックを段階的に構築 |
| 条件付き集計（CASE + 集計関数） | ファネルのステージ別カウント、フラグ別集計 |
| 複数テーブルJOIN（INNER / LEFT） | 4テーブル結合による売上分析、媒体×採用の横断集計 |
| 日付関数（DATE_FORMAT, DATEDIFF） | 月次集計、採用リードタイム算出 |
| NULL安全な除算（NULLIF） | ゼロ除算を防止した比率計算 |
