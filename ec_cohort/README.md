# コホート分析・リテンション分析

## プロジェクト概要

ECサイトの顧客を「初回購買月（コホート）」ごとにグループ化し、
その後の月次継続率（リテンション）を追跡する分析です。

顧客のライフサイクル把握やLTV向上施策の効果測定に活用されます。

**使用データ:** `ec_sales` プロジェクトの `customers` / `orders` / `order_items` テーブルを参照

## 作成意図

コホート分析は「リテンション（継続率）」を可視化する代表的な手法であり、グロースや顧客成功（CS）領域で不可欠なスキルです。
このプロジェクトを選んだ理由は、**EC売上分析・RFM分析とは異なる時系列の視点**を加えることで、分析の幅を実証するためです。

**ビジネス観点：**
- 「新規獲得と既存維持のどちらに投資すべきか」という問いに答えるには、コホートごとのリテンション推移を把握することが前提となる
- 特定コホートの急落を検出することで、施策・障害・季節要因の影響を後追い検証できる実践的な課題設定にした

**技術観点：**
- `TIMESTAMPDIFF(MONTH, ...)` で「初回購買からの経過月」を算出し、`CASE + COUNT DISTINCT` で2次元のリテンションマトリクスを構成する手法は、**あらゆる継続率分析の汎用テンプレート**として示した
- 3段階CTEで①コホート定義→②経過月マッピング→③集計へと段階的に構成することで、複雑な変換ロジックを明確に分離した

---

## コホート分析とは

「初回購買月」でユーザーをグループ化し、N ヶ月後にどれだけ残っているかを追跡する手法。

```
コホート 2024-01 (5人)
  └─ m0: 5人(100%) → m1: 1人(20%) → m2: 2人(40%) → m3: 1人(20%) ...

コホート 2024-05 (2人)
  └─ m0: 2人(100%) → m1: 1人(50%) → m2: 1人(50%) → m3: 1人(50%) ...
```

## ER図（参照テーブル）

```
customers ──┐
            │ 1:N
            └──── orders ──── order_items
                    │
                    └── MIN(order_date) = 初回購買日（コホート定義）
```

## クエリ一覧

| # | ファイル | 分析テーマ | 使用テクニック | ビジネス価値 |
|---|---------|-----------|--------------|------------|
| 01 | `01_cohort_definition.sql` | コホート定義 | MIN(), DATE_FORMAT | 各顧客の初回購買月を特定 |
| 02 | `02_cohort_month_mapping.sql` | 経過月マッピング | TIMESTAMPDIFF(MONTH) | 「初回からN ヶ月後」を付与 |
| 03 | `03_cohort_retention_table.sql` | リテンションテーブル | 条件付き集計(CASE + COUNT DISTINCT) | コホート×月の2次元マトリクス |
| 04 | `04_cohort_retention_rate.sql` | リテンション率(%) | CTE 3段, NULLIF, ROUND | 各コホートの月次残存率 |
| 05 | `05_avg_retention_by_month.sql` | 平均リテンションサマリ | AVG, サブクエリ | 全コホート横断の傾向分析 |

## 読み方のポイント

- **m0** は初月（全員100%）
- **m1以降** の数値が高いほどリテンションが良い
- 特定コホートだけ急落している場合、その時期の施策や障害を調査する手がかりになる
- 横方向で「同一コホートの時系列推移」、縦方向で「同一経過月の世代間比較」が可能
