# RFM顧客セグメンテーション分析

## プロジェクト概要

ECサイトの注文データを用いて、顧客をRFM（Recency・Frequency・Monetary）の3軸でスコアリングし、
マーケティング施策の優先度判定に活用できるセグメント分類を行います。

**使用データ:** `ec_sales` プロジェクトの `customers` / `orders` / `order_items` テーブルを参照

## RFMとは

| 指標 | 意味 | 高スコア = |
|------|------|-----------|
| **R**ecency | 最終購買からの経過日数 | 最近購買した |
| **F**requency | 購買回数 | 何度も買っている |
| **M**onetary | 累計購買金額 | 多く使っている |

## ER図（参照テーブル）

```
customers ──┐
            │ 1:N
            ├──── orders ──── order_items ──── products
            │       │
            │       └── status IN ('paid','shipped') で絞り込み
```

## クエリ一覧

| # | ファイル | 分析テーマ | 使用テクニック | ビジネス価値 |
|---|---------|-----------|--------------|------------|
| 01 | `01_rfm_scores.sql` | RFMスコア算出 | CTE, DATEDIFF, CURDATE() | 顧客ごとのR/F/M値を一覧化 |
| 02 | `02_rfm_decile.sql` | 5段階スコアリング | NTILE(5)の多軸適用 | 顧客間の定量比較を可能にする |
| 03 | `03_rfm_segment.sql` | セグメント分類 | CASE多分岐, CTE3段 | VIP/優良/新規/休眠/離脱を自動判定 |
| 04 | `04_segment_summary.sql` | セグメント別集計 | GROUP BY, AVG, NULLIF | セグメントの特性を俯瞰 |
| 05 | `05_churn_risk.sql` | 離脱リスク顧客一覧 | HAVING, DATEDIFF | フォロー対象の優先度付き抽出 |

## セグメント定義

| セグメント | 条件 | 想定施策 |
|-----------|------|---------|
| VIP | R≥4, F≥4, M≥4 | ロイヤルティプログラム・限定オファー |
| 優良顧客 | 合計≥11 | クロスセル・アップセル提案 |
| 新規有望 | R≥4, F≤2 | 2回目購買促進キャンペーン |
| 休眠リスク | R≤2, F≥3 | リマインドメール・クーポン配布 |
| 離脱 | R≤2, F≤2 | ウィンバックキャンペーン |

## 実行方法

```bash
# 事前に ec_sales のスキーマ・データを投入した状態で実行
mysql -u root sql_portfolio < ec_rfm/queries/01_rfm_scores.sql
```
